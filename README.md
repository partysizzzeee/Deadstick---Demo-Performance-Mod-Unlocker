DeastickPerf.dll is a standalone performance mod that changes a lot of things about how the game renders. In my testing I saw almost double the performance when comparing native vs. potato mode. 4 Levels of quality that are hotkey selectable. 

DeadstickUnlocker.dll is a small menu that allows the demo to be extended beyond the limits that the devs have set. Removes the barrier for the demo zone, as well as allows for more missions to be generated. 

Melonloader required for install and use. Install either or both mods into Mods folder that melonloader creates upon installation

I have completely overhauled the entire mod. There are 4 levels to the quality of the mod to better account for lower end PCs, as well as a built in resolution scalar so you can tweak things on the fly. I saw incredible performance gains. On native everything, the game runs at about 80 fps on max settings. With the mod on lowest settings I saw 160 fps on the ground and over 140 fps when flying over the map. Multiple hotkeys are used in this version. One to toggle between the levels of quality, one for toggling the scale of the resolution, and another one just for cloud resolution. I found that the clouds were the biggest problem for performance, so that is why they get their own hotkey for resolution.
